# Product Requirements — SignalIQ

**Tagline:** Find the signal. Fix the problem.
**Descriptor:** Customer Intelligence Platform

Turn scattered customer feedback into a prioritized, explainable list of problems to fix next.

Core workflow: Collect → Analyze → Discover → Prioritize → Act → Report

Demo scenario: an online shopping business with payment, delivery, quality, support, and performance feedback. Sample data is labelled synthetic.

See the original requirements in the documentation bundle. Implemented features match FR-1 through FR-12: sample data, entry, CSV import, explorer, analysis, dashboard, grouping, priority scoring, recommendations, tracking, report export, and Adaption Lab.

Non-goals: auth, billing, third-party review ingestion, custom model training.
