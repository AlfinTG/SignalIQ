# Design System — SignalIQ

Premium, restrained SaaS: light canvas, dark navy sidebar, blue accent.

## Tokens

- `navy-950`: `#14243A`
- `blue-600`: `#2F6FED`
- `blue-50`: `#EFF5FF`
- `text-primary`: `#192638`
- `text-secondary`: `#667085`
- `surface`: `#FFFFFF`
- `surface-subtle`: `#F6F8FB`
- `border`: `#E2E8F0`
- `positive`: `#23845D`
- `warning`: `#A56B16`
- `negative`: `#C54848`

Never communicate sentiment or priority by colour alone.

## Layout

Desktop: compact navy sidebar, page heading, KPI row, charts, issue list.
Mobile: off-canvas menu; stacked cards; horizontally scrollable tables.

## Quality bar

The dashboard should show what is happening, why it matters, and what to do next.
